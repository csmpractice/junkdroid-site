---

## 🚀 Deployment Info

This site is deployed via **GitHub Pages** and connected to a custom domain using **Cloudflare DNS**.

### GitHub Pages Configuration
- Branch: `main`
- Folder: `/ (root)`
- Custom Domain: `www.junkdroid.app`
- Enforce HTTPS: Enabled after successful verification

### Cloudflare DNS Settings

| Type  | Name | Target                     | Proxy |
|-------|------|----------------------------|--------|
| CNAME | www  | `csmpractice.github.io`    | DNS only ✅ |

*DNS propagation can take 10–30 minutes.*
